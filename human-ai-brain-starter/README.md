# HUMAN × AI = HUMAN WITH AI BRAIN

Standalone starter app source is available in the downloadable ZIP provided in this conversation. This repository folder records project setup and deployment instructions.

## Quick start
1. Unzip `HUMAN_AI_BRAIN_25_Specifications_Starter.zip`.
2. Run `npm install`.
3. Run `npm run dev`.

For full source files, upload/extract the starter ZIP into a new repository or deploy the ZIP to Vercel/Netlify/Cloudflare Pages. The app includes 25 specifications, tool links, search and filters, completion state for the session, and Markdown template exports.
